# SMO.H3 Studio 0.1.2 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 修复润色凭据与超时问题，提供 H3 模型/比例/分辨率/字幕选择、中文 Skill、真实进度、保存状态及圆形品牌界面，并交付 0.1.2 portable。

**架构：** 复用 `HardwareWorkflowStore` 生成独立参数副本；提示词补充与 H3 节点参数分离。真实帧进度写入现有 `metadata.progress`，不迁移数据库。LLM 发现、测试和长润色使用独立超时与明确的密钥状态。品牌资源用 Alpha 蒙版生成透明圆形图标。

**技术栈：** Electron、React、TypeScript、Zod、Sharp、Node:sqlite、Vitest、Testing Library、Playwright、electron-builder。

## 文件结构与职责

- `src/shared/types.ts`：`LlmProfileView`、`AspectRatio`、`WorkProgress` 和元数据类型。
- `src/shared/generation-options.ts`：比例/分辨率选项、模型默认值和 `withSubtitlePreference`。
- `src/main/llm-config.ts`：凭据解密状态和完整凭据解析。

- `src/main/hardware.ts`、`src/main/hardware-workflows.ts`：模型/比例/分辨率副本。
- `src/main/generation.ts`：字幕合并与真实进度元数据。
- `src/renderer/GenerationOptions.tsx`：制作台共用的模型、比例、分辨率和字幕控件。
- `src/renderer/skill-options.ts`：中文 Skill 名称和一句话说明。
- `src/renderer/WorkProgressBar.tsx`：不确定/确定/完成/失败进度显示。

- `scripts/prepare-brand.mjs`：透明圆形 PNG/ICO 生成。

- `tests/e2e/real-llm.spec.ts`：使用重存凭据的真实模型与短润色验收。

- [ ] **步骤 3：实现凭据状态、超时和状态标记**

在 `src/shared/types.ts` 添加：

```ts
export type LlmKeyStatus = 'valid' | 'reenter-required';
export interface LlmProfileView extends LlmProfile {
  keyStatus: LlmKeyStatus;
}
```

`getProfile()` 返回 `LlmProfileView | null`，解密失败只影响 `keyStatus`，不清空 Base URL/模型。`getCredentials()` 将解密失败转换为明确的重新输入提示。

`LlmService` 构造函数改为 `constructor(timeoutMs = 20_000, polishTimeoutMs = 120_000)`。`request` 接收调用级 timeout；`listModels` 和 `testModel` 使用 `timeoutMs`，`chatCompletion` 默认使用 `polishTimeoutMs`，并允许显式覆盖。

设置页按 `keyStatus` 优先显示「需要重新输入密钥」；字段匹配且无新密钥输入显示「已保存」；修改后显示「有未保存修改」。重存后清空密钥输入并恢复 `valid`，保留异步卸载保护。
