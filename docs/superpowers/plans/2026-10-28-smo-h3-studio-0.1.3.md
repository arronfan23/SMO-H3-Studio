# SMO.H3 Studio 0.1.3 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 保留切页前的制作台状态，支持文字和音频自动时长，允许安全删除作品记录及生成视频，并修复真实 `ffprobe` 路径。

**架构：** 制作台通过隐藏而非卸载保留现有 React 状态；自动时长在渲染层解析为数字后继续复用现有 IPC 与重试快照。新增 `WorkService` 统一管理作品状态、输出文件和 SQLite 删除，`ffprobe` 只修正默认路径，不改变环境变量覆盖契约。

**技术栈：** Electron、React、TypeScript、Zod、Node:sqlite、Node:fs、Vitest、Testing Library、Playwright、electron-builder。

- [ ] **步骤 3：实现确定性估算函数**

`src/shared/duration.ts`：

```ts
export function estimateNarrationDuration(text: string): number {
  const hanCount = text.match(/\p{Script=Han}/gu)?.length ?? 0;
  const latinText = text.replace(/\p{Script=Han}/gu, ' ');
  const wordCount = latinText.match(/[A-Za-z0-9]+(?:['-][A-Za-z0-9]+)*/g)?.length ?? 0;
  if (hanCount + wordCount === 0) {
    return 8;
  }

  const seconds = hanCount / 4 + wordCount / 2.5 + 2;
  const rounded = Math.ceil(seconds * 2) / 2;
  return Math.min(15, Math.max(4, rounded));
}
```

- [ ] **步骤 3：实现存储删除与 `WorkService`**

`Store.deleteWork`：

```ts
deleteWork(id: string): Work {
  const work = this.getWork(id);
  if (work === null) {
    throw new Error(`Work not found: ${id}`);
  }
  if (work.status !== 'done' && work.status !== 'failed') {
    throw new Error('Only completed or failed works can be deleted');
  }
  const result = this.db
    .prepare("DELETE FROM works WHERE id = ? AND status IN ('done', 'failed')")
    .run(id);
  if (result.changes !== 1) {
    throw new Error('Only completed or failed works can be deleted');
  }
  return work;
}
```

`WorkService.deleteWork(id)` 先读取并检查相同状态，再对非空 `outputPath` 调用 `removeOutput`，最后调用 `store.deleteWork(id)`。`removeOutput` 必须：

```ts
const root = resolve(this.outputDirectory);
const candidate = resolve(filePath);
assertInside(root, candidate);
if (!['.mp4', '.webm'].includes(extname(candidate).toLowerCase())) {
  throw new Error('Work output must be an MP4 or WebM video');
}
const stats = await lstat(candidate).catch((error: NodeJS.ErrnoException) => {
  if (error.code === 'ENOENT') return null;
  throw error;
});
if (stats === null) return;
if (!stats.isFile() || stats.isSymbolicLink()) {
  throw new Error('Work output must be a regular video file');
}
assertInside(await realpath(root), await realpath(candidate));
await this.remove(candidate, { force: true });
```

`assertInside` 使用 `relative`、`isAbsolute` 和 `sep` 拒绝空相对路径、`..` 和目录逃逸。`WorkServiceOptions` 包含 `outputDirectory`、`store`、`removeFile?: typeof rm`。
