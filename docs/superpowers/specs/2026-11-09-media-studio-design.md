# SMO.H3 Studio 语音、图像与视频制作台设计

日期：2026-11-09

## 目标

将制作台扩展为“语音 / 图像 / 视频”三个同级主模式。语音支持本地文字配音和声音克隆，图像使用 Qwen Image 2.1 标准版本地文字生图，视频完整保留现有 MiniMax H3 能力。三种生成共用单任务执行、进度、重试和作品管理，并允许语音作品直接进入音频数字人制作。

## 已确认范围

- 图像首版只做文字生图，不做图片编辑或多参考图。
- 语音采用本地 Qwen3-TTS，不使用 Fish Audio 本地模型或云端 API。
- 语音作品可以一键带入“视频 > 音频数字人”。
- 语音输出支持 WAV、MP3、FLAC、M4A，默认 WAV。
- 图像和视频步数均可通过加减按钮或直接输入修改。
- 全局同一时间只执行一个生成任务，不提供排队。
- 移除“我的作品”的“等待中”筛选。
- 当前模特参考图完整显示，音频支持拖入，音频数字人支持录音。

## 架构

采用混合本地架构：

- 视频继续使用现有 ComfyUI H3 工作流、模型和硬件档位，不改变已有节点图语义。
- 图像继续通过 ComfyUI 原生 Qwen Image 2.1 节点和工作流运行。
- 语音使用独立 Python 3.12 环境与本地 Qwen3-TTS 服务，避免依赖污染 ComfyUI。服务仅绑定 `127.0.0.1`，由应用管理生命周期，不需要 API Key。
- 三类任务共用主进程任务协调器、统一 IPC、作品存储和媒体授权。任务协调器以原子操作保证最多一个活动任务；拒绝新任务时不得留下作品记录。

## 模型与安装

### 视频

现有 H3 基础环境、模型清单、SM89/SM120 运行时和 Spark 加速保持不变。Spark 节点读取用户修改后的调度器步数。

### 语音

安装以下按需组件：

- `Qwen3-TTS-12Hz-0.6B-CustomVoice`：固定音色文字配音及情绪/语气说明。
- `Qwen3-TTS-12Hz-0.6B-Base`：参考音频声音克隆。
- `Qwen3-TTS-Tokenizer-12Hz`：两种语音能力共用的分词器。

语音组件有独立的下载、校验、安装和就绪状态。未安装时只禁用语音生成，不影响图像和视频。下载沿用现有 HTTPS、SHA256、进度、取消和失败重试机制。

### 图像

使用 Qwen Image 2.1 标准版的 ComfyUI 兼容权重，默认 25 步，不使用 Turbo 的固定 8 步 `ManualSigmas` 调度。图像模型有独立按需下载和校验状态；未安装时不影响语音和视频。8 GB 显存设备采用低显存/卸载候选配置，生成性能和稳定性需要真实硬件验收，不将兼容性候选描述为保证可用。

## 制作台交互

### 主布局

采用已确认的 A 布局：语音、图像、视频为同级主模式。模特栏只在视频模式显示；语音和图像使用完整工作区。视频内部保留“文字生视频 / 音频数字人”两个子模式。各面板保持挂载，切换主模式、子模式或应用页面不得清空未提交草稿。

### 语音

语音面板包含“固定音色 / 声音克隆”两个子模式。

固定音色模式提供：

- 口播文字。
- 模型支持的音色列表。
- 语言选择，默认自动识别。
- 情绪/语气说明。
- 输出格式，默认 WAV。

声音克隆模式提供：

- 口播文字。
- 参考音频的选择、拖入、试听和移除。
- 可选参考音频原文；留空时使用仅说话人向量模式，并明确提示克隆质量可能降低。
- 语言选择，默认自动识别。
- 输出格式，默认 WAV。

Qwen3-TTS 首先生成 WAV。选择 MP3、FLAC 或 M4A 时由本地 FFmpeg 转换，最终作品保存为用户选择的格式。生成完成后提供“用于音频数字人”：切换到视频主模式和音频数字人子模式，并带入选定输出音频及其实际时长。

### 图像

图像面板提供提示词、比例/分辨率、随机种子和步数。步数默认 25，显示推荐值。结果进入“我的作品”，支持预览、重命名、打开目录和删除。

### 视频

保留现有提示词润色、Skill、时长、比例/分辨率、随机种子和硬件档位行为。新增调度器步数：文字视频默认 8，音频数字人默认 6。

图像与两种视频生成的步数控件均为正整数步进器，范围 1-100，支持加减按钮和直接输入。高于模型推荐值时提示耗时增加，但不阻止提交。语音没有采样步数控件。

当前模特图片使用原始宽高比完整展示，不裁切；容器只限制最大尺寸，不强制图片填充固定比例。

### 音频选择与录音

音频数字人的选择控件支持文件对话框和单文件拖入。拖入文件通过 Electron `webUtils` 获取真实路径并由主进程授权，渲染进程不能提交任意路径绕过授权。

录音功能提供开始、停止、计时、试听、重录和移除。只有用户点击开始后才申请麦克风权限。录音保存到应用管理的录音目录，并转换为单声道、24 kHz、16 位 WAV，再作为当前音频使用。权限拒绝、无麦克风、读取失败和转换失败均显示可理解的中文错误，不改变已有音频选择。

## 单任务与状态

- 语音、图像、视频共用一个活动任务锁。
- 活动任务存在时，所有生成入口禁用；直接调用 IPC 也必须拒绝新任务。
- 不再建立等待队列，不在“我的作品”提供“等待中”筛选。
- `pending` 仅作为兼容旧数据和任务启动瞬间的内部状态保留；不得形成用户可排队等待的工作流。
- 当前任务可取消。完成、失败、取消和应用退出都必须释放任务锁并清理相关子进程或 ComfyUI 提示任务。

## 作品与数据兼容

生成请求按模式区分为视频、图像和语音：

- 视频请求沿用 `text` / `audio`，新增 `steps`。
- 图像请求使用 `image`，包含提示词、尺寸、种子和步数，不要求模特。
- 语音请求使用 `speech`，包含固定音色或克隆参数、文本、输出格式，不要求模特。

旧作品继续可读。新语音和图像作品允许 `avatarId = null`，标题回退分别为“语音作品”和“图像作品”，不显示“未知模特”。作品元数据保存完整请求快照，用于失败重试和版本兼容。

作品列表新增“语音”和“图像”筛选，保留视频子类型及“运行中 / 已完成 / 失败”，移除“等待中”。作品卡片按类型显示音频播放器、图片或视频。删除作品同时删除其真实输出文件和该作品生成的附属缩略图，但不删除用户原始参考音、模特照片或被其他作品引用的文件。

## IPC 与安全

- 新增或扩展的 IPC 使用严格 Zod schema，拒绝未知字段和错误类型。
- 新增录音保存、拖入音频授权、模型组件状态和组件安装接口；不提供任意路径写入能力。
- 所有用户选择的参考音、生成输出和录音通过 MediaRegistry 授权或管理根目录校验。
- 图像和语音输出路径必须限制在应用输出目录，防止历史记录或模型服务返回路径逃逸。
- API Key、用户文本、参考音和照片不写入日志。

## 错误处理

- 模型未安装、下载失败、服务启动失败、麦克风失败、格式转换失败和 ComfyUI 失败分别给出明确错误。
- 可选组件失败不得破坏基础 H3 环境。
- 任务失败后保留可重试记录；重试重新校验输入文件和模型状态。
- 应用退出时关闭语音服务，并沿用现有 ComfyUI 和便携版进程清理规则。

## 测试与验收

- 单元测试覆盖请求 schema、三类请求校验、步数写入、Spark 步数同步、音频格式转换、单任务互斥、无排队、重试和旧作品兼容。
- 渲染测试覆盖主模式草稿保留、完整模特图、音频拖入、录音状态、输出格式、语音带入视频和作品筛选。
- Electron E2E 使用模拟 Qwen 图像输出和模拟语音服务，不依赖真实模型下载，覆盖三类作品及跨模式衔接。
- 打包测试确认可选模型、密钥和用户素材不进入安装包，组件清单和本地服务脚本完整。
- 真实硬件验收分别执行固定音色、声音克隆、四种音频格式、Qwen 文字生图和两种 H3 视频模式，验证输出文件、实际时长、任务锁释放与删除行为。

## 非目标

- 不做 Fish Audio 集成。
- 不做图片编辑、多参考图、多任务队列、云端 TTS 或文本生成音频的 LLM API。
- 不改变现有登录/会员计划，不在本次引入服务器依赖。
