# SMO.H3 Studio 0.1.3 设计规格

日期：2026-10-28

## 背景与目标

本次处理 4 个已确认的问题：切换模块后制作台草稿丢失、文字时长不能留空自动计算、作品无法删除，以及音频生成因 `ffprobe` 路径错误而失败。

已确认的根因：

- `App.tsx` 仅在当前页为制作台时挂载 `StudioPage`，切页会卸载表单并清空本地状态。
- 文字和音频表单都把时长设为必填数字，没有自动时长的解析规则。
- 作品领域只有列表与重试，没有删除 IPC、存储方法、文件安全校验和界面入口。
- 默认 `ffprobe` 路径多了一层 `ComfyUI`。实际文件位于 `G:\H3Selflift整合包\ComfyUI_SelfLift_Spark_SM120_CUDA130\tools\ffmpeg\ffprobe.exe`，且该可执行文件可以正常运行。

采用已批准的方案 A：保持制作台挂载、在本地确定性计算自动时长、新增带路径保护的作品删除服务、修正默认 `ffprobe` 路径。

## 范围

### 包含

- 制作台在模块切换期间保留未提交状态。
- 文字模式按口播内容自动估算时长，音频模式按剩余音频自动确定截取时长。
- 完成或失败作品的记录与生成视频删除。
- 默认 `ffprobe` 路径修复和真实音频读取验证。
- 单元测试、端到端测试、代码审查和 0.1.3 portable 交付。

### 不包含

- 不在应用重启后恢复未提交草稿；本次只保证模块切换不丢失。
- 不取消或删除等待中、运行中的任务。
- 不删除模特照片、用户原始音频、上传暂存目录或整个输出目录。
- 不让 LLM 自行决定时长，不改变 H3 的 4–15 秒文字时长限制。
- 不修改 H3 整合包中的模型、冻结工作流或启动脚本，不执行真实用户素材视频生成。

## 1. 制作台草稿保留

- `App` 始终挂载 `StudioPage`，通过带 `hidden` 属性的容器控制可见性。隐藏时不可见、不可交互，也不参与可访问性树。
- 数字模特、我的作品和设置页仍按现有方式挂载与卸载。
- 制作台内部的原文、润色结果、当前提示词标签、文字/音频模式、音频选择、截取参数、H3 选项和当前任务状态均因组件不再卸载而保留。
- 后台任务轮询可以继续，切回制作台时显示最新真实状态，不伪造完成状态。
- 不增加 `localStorage`、`sessionStorage` 或数据库草稿表。

## 2. 自动时长

### 共用原则

- 时长输入支持 `number | ''`；空字符串表示自动，其他校验和提交仍使用解析后的有限正数。
- `GenerationRequest`、IPC 和作品元数据继续保存解析后的数字时长，不把空值传入主进程。重试沿用已保存的数字，不因后续编辑而改变。
- 手动输入行为保持兼容。文字手动时长仍需在 4–15 秒内，音频截取仍不能超过实际音频范围。

### 文字模式

- 默认仍为 8 秒；用户清空输入后进入自动模式，并在输入框下方看到当前预估值。
- 自动模式把当前原文视为口播内容。中文按汉字数量每秒 4 字估算，英文按单词数量每秒 2.5 词估算；混合文本累加两部分时间。
- 估算口播时间后增加 2 秒无口播收尾，向上取整到 0.5 秒，再限制在 4–15 秒。没有可计数汉字或英文单词时使用 8 秒。
- AI 润色前解析一次自动时长，并缓存该次润色结果对应的数值。使用润色结果生成时沿用缓存值，避免把完整 H3 YAML 当作口播重新估算。
- 使用原文生成时按当前原文计算。修改手动时长后始终以手动值为准。
- 提示文案保持简短，例如「留空自动：约 8.5 秒（含 2 秒收尾）」。

### 音频模式

- 选择音频并读取元数据后，仍默认填入完整音频时长，保持现有行为。
- 用户清空「截取时长」后，自动值等于 `audioSeconds - trimStart`；界面显示剩余秒数。
- 起始截取必须小于实际音频时长，自动剩余时长必须大于 0。提交后仍由主进程通过 `ffprobe` 对暂存音频再次校验。
- 音频工作流现有的 48 帧收尾保持不变，不重复追加时长。

## 3. 作品记录与视频删除

### 领域与 IPC

- 新增作品删除服务，负责状态检查、输出路径校验、文件删除和数据库删除。
- `Store.deleteWork` 只允许删除 `done` 或 `failed` 记录，并返回被删除记录；不存在或状态不允许时给出明确错误。
- 新增严格校验的 `works:delete` IPC、preload 方法和 `SmoApi.works.delete(id)`。

### 文件安全

- 仅允许删除配置的 ComfyUI 输出目录内的 `.mp4` 或 `.webm` 普通文件。规范化并解析真实路径后，拒绝目录穿越、绝对路径逃逸、符号链接和目录。
- 输出路径为空或文件已不存在时，可以只删除数据库记录。
- 先删除视频文件，再删除数据库记录。文件删除失败时保留记录并返回错误；不声称文件已删除。
- 不删除任何源素材，也不递归删除目录。

### 界面

- 完成或失败的作品在操作区显示带垃圾桶图标的「删除」按钮；等待中和运行中不显示删除入口。
- 点击后打开确认弹窗，显示模特名称和生成文件名，明确记录与视频会一起删除且不可撤销。
- 删除期间禁用确认按钮。成功后关闭弹窗并刷新列表；失败时保留弹窗并展示真实错误。
- 沿用现有模特删除弹窗、危险按钮和异步卸载保护模式。

## 4. `ffprobe` 路径修复

- 默认路径修正为 `G:\H3Selflift整合包\ComfyUI_SelfLift_Spark_SM120_CUDA130\tools\ffmpeg\ffprobe.exe`。
- `SMO_FFPROBE_PATH` 和由 `SMO_FFMPEG_PATH` 派生路径的优先级保持不变，显式传入的 `ffprobePath` 仍拥有最高优先级。
- 保留现有参数、10 秒超时、隐藏窗口和错误脱敏行为。
- 除单元测试外，使用测试音频通过默认真实路径读取时长，验证原始 `ENOENT` 已消失；不提交真实 H3 视频生成。

## 5. 验证与交付

- 先写失败测试，覆盖切页草稿、自动时长边界、润色与生成时长一致、音频剩余时长、作品状态保护、输出路径逃逸、删除失败和 IPC 契约。
- 端到端验证切到数字模特、作品和设置后草稿仍在，以及确认删除后记录和测试视频均消失。
- 运行完整单元测试、类型检查、普通 E2E、package E2E 和真实 `ffprobe` 验证。
- 对规格与代码质量分别审查，修复全部 Critical/Important 后再交付。
- 版本提升为 0.1.3，重建 portable，复制到正式 `release` 目录并核对 SHA256，更新桌面快捷方式和 PR #1，保留 worktree。
