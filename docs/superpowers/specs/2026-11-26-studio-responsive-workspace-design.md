# SMO.H3 Studio 制作台响应式工作区设计

日期：2026-11-26

## 背景

制作台当前把表单、任务状态和生成结果依次放在同一个表单列中。图像控制区另有 `780px` 最大宽度，生成结果缺少统一的媒体尺寸约束。窗口最大化后，较窄的控制区与按自然尺寸显示的结果混在同一列；窗口还原后，参数和媒体又依赖少量窗口级断点，无法根据扣除左侧导航后的真实内容宽度重排。

这会造成宽屏空间浪费、结果图片撑破布局、进度与预览位置不稳定，以及最大化和还原后的视觉跳跃。

## 目标

- 保留现有绿色品牌配色、左侧导航、中文字体和控件风格。
- 语音、图像、视频使用一致的编辑区与输出区结构。
- 布局根据制作台容器的实际可用宽度重排，而不是按设备名称判断。
- 最大化、还原和拖动调整窗口时保留所有草稿、参考素材、任务状态与结果。
- 大尺寸横图、竖图、视频和长文本均不得造成横向溢出、遮挡或控件重叠。

## 非目标

- 不修改 ComfyUI 工作流、生成算法、模型选择或任务数据格式。
- 不修改整体品牌配色、应用导航和其他页面的信息架构。
- 不增加新的任务系统、历史记录系统或独立预览窗口。
- 不为响应式改版引入新的前端框架或状态管理库。

## 选定方案

采用“自适应双栏工作区”。宽屏下编辑区与输出区同时显示；空间不足时输出区移动到编辑区下方。方案只重组现有 React 输出区域和共享样式，生成逻辑保持不变。

### 页面宽度

- `.studio-page` 继续居中，最大内容宽度由 `1180px` 调整为 `1440px`，避免宽屏浪费，同时避免在 4K 屏幕上无限拉伸。
- 制作台建立独立的 CSS 容器上下文，以制作台宽度而不是整个窗口宽度作为双栏判断依据。
- 默认使用单栏。容器可用宽度达到 `1040px` 时使用双栏：编辑区约 55%，输出区约 45%，输出区最小宽度为 `320px`。
- 容器低于 `1040px` 时，输出区紧跟编辑区，不产生横向滚动。

### 编辑区

- 编辑区依次容纳组件准备状态、模式切换、提示词、参考素材、生成参数和主生成按钮。
- 参数行使用制作台专用的自动适配网格。每列理想最小宽度为 `220px`，空间足够时两列，不足时单列。
- 提示词输入框保留可调整高度能力，并设置合理的默认与最小高度；矮窗口规则不能把它压缩到难以编辑。
- 所有输入控件、标签和参数组均允许收缩，长选项不得把网格撑宽。
- 音频数字人的当前模特从独立的外层列移到编辑区顶部，使用横向参考区展示。照片使用 `object-fit: contain`，保持完整可见，不再占用第三个页面列。

### 输出区

- 输出区统一容纳 `JobStatus` 与 `GenerationResultPreview`，标题为“任务与结果”。
- 尚未生成时显示稳定的空预览区域，不再让结果区域从无到有推动布局。
- 宽屏且视口高度至少为 `700px` 时，输出区在主内容滚动容器中吸顶；矮窗口中取消吸顶，避免结果无法阅读。
- 任务 ID、阶段文字、百分比、错误信息和操作按钮均允许合理换行。进度说明保留稳定的最小高度，但不为限制高度而截断错误。
- “打开目录”和“进入我的作品”在输出区底部排列，空间不足时自动换行。
- 失败时保留用户输入和参数，继续使用编辑区现有的生成按钮重试，不创建第二份任务状态。

### 媒体规则

- 图片使用原始宽高比，在输出区内完整显示：`max-width: 100%`、自动高度、居中、`object-fit: contain`，并限制相对视口高度。
- 视频宽度不超过输出区，保持原始宽高比并限制相对视口高度。
- 音频播放器占满可用宽度但不溢出。
- 图片和视频均不通过固定高度裁剪内容。

## 组件结构

新增一个轻量的共享制作台布局组件，提供 `editor` 与 `output` 两个明确区域。它只负责结构，不拥有任务或表单状态。

- `SpeechForm`：编辑区保留语音设置与录音，输出区放置语音任务和音频预览。
- `ImageForm`：编辑区保留文字生图、参考生图及各自独立提示词，输出区放置图像任务和图片预览。
- `TextToVideoForm`：文字生视频和图片生视频共用同一输出结构。
- `AudioDigitalHumanForm`：编辑区顶部接收并展示当前模特，其余音频数字人设置保持不变。
- `StudioPage`：继续负责制作模式切换和意图导航，不再为音频数字人建立额外的人物预览列。

现有 `useActiveJob`、`useWorkResult`、IPC 和任务持久化接口保持不变。窗口缩放只触发 CSS 重排，不触发 React 重挂载或数据重新提交。

## 状态与交互

- 空状态：输出区显示“生成结果”和简短空状态，不显示伪造的进度。
- 运行中：显示真实任务状态、阶段、进度、已用时间和现有取消能力。
- 已完成：显示真实媒体与现有目录、作品页操作。
- 失败：显示具体错误，保留编辑内容，允许通过现有主按钮重试。
- 窗口尺寸变化：立即重排，不使用会延迟操作或造成布局抖动的宽屏动画。
- 键盘与可访问性：保留现有标签、tab 顺序、焦点样式和状态播报；输出区顺序始终跟在编辑区之后。

## 验收与测试

先增加会失败的 Electron 回归场景，再实施布局修改。

1. 在 `1280 × 820` 与 `1920 × 1080` 下，编辑区和输出区左右排列，所有控件位于各自面板内。
2. 在 `960 × 640` 下，输出区位于编辑区下方，页面不存在非预期横向溢出。
3. 连续执行还原、最大化、再次还原以及拖动调整大小后，提示词、参数、参考素材、任务 ID 和结果保持不变。
4. 使用真实模拟任务生成大横图与竖图，结果完整位于输出区内，不覆盖参数、进度或按钮。
5. 语音、文字生视频、图片生视频和音频数字人均使用相同输出结构，并保留原有生成行为。
6. 运行类型检查、完整单元测试、完整 Studio Electron 测试和最终打包态测试，并人工检查关键截图。
