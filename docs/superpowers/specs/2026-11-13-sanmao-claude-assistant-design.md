# 三脚猫 Claude 助手接入设计

## 目标

在 SMO.H3 Studio 增加与“制作台、数字模特、我的作品、设置”同级的“ 三脚猫 ”导航，提供真正可用的 Claude 对话、连接配置、流式回复、停止和新建会话。首版不允许助手读取文件、执行 Shell、修改工作流或直接启动生成。

## SDK 与边界

- 使用官方 `@anthropic-ai/claude-agent-sdk`，固定当前核实的 `0.3.323` 版本。该包用于嵌入 Claude Code 的 Agent 能力，不在应用里嵌入终端 UI。
- SDK 仅在 Electron 主进程加载。渲染进程只能调用严格校验的 IPC，不接触 SDK 进程参数或密钥。
- 三脚猫使用独立的 Anthropic 兼容配置，不复用现有 OpenAI 兼容 LLM 配置。现有提示词润色流程不受影响。
- 首版禁用 SDK 工具，不授予文件、Shell、ComfyUI、作品删除或生成权限。后续工作流工具必须单独设计、逐项授权并由用户确认。

## 连接配置与安全

- 页面提供服务地址、API Key 和模型名称字段。服务地址默认官方 Anthropic API，可修改为兼容端点；模型名称使用可编辑输入框，不假设上游支持模型列表接口。
- API Key 为只写字段，保存后界面只显示“已保存”状态，不返回明文。密钥使用现有 Windows DPAPI 方案加密存储，日志、错误和 IPC 响应不得包含密钥。
- 保存前校验 URL 协议、凭据、查询和片段，模型名称不得为空。连接测试只发送极短测试请求并返回成功状态或脱敏错误。
- 只有用户点击发送或测试时，文字才会发送到配置的 Claude 服务。离线或 SDK 不可用时，现有本地制作功能不受影响。

## 主进程与会话

- 新增 `SanmaoService`，封装 SDK 初始化、配置加载、连接测试、流式请求、取消和关闭。
- 每个会话由主进程记录 SDK session ID；同一页面的后续消息使用该会话，新建会话会清除本地消息并停止旧请求。
- 同一时间只允许一个三脚猫请求。发送、停止和页面切换不得造成重复请求或旧回复写入新会话。
- 请求使用 AbortController 取消，并设置有限超时。SDK 的 system、assistant、stream event 和 result 消息只映射为必要的文本与状态，不向页面暴露原始进程信息。
- 当前会话在应用页面切换后保留；应用重启后清除会话和消息历史，首版不写入聊天记录数据库。

## IPC 契约

- `sanmao:getProfile`：返回服务地址、模型、是否已保存密钥和保存状态，不返回密钥。
- `sanmao:saveProfile`：校验并保存服务地址、模型和可选的新密钥。
- `sanmao:testConnection`：使用已保存或当前输入配置进行脱敏连接测试。
- `sanmao:send`：接收当前会话 ID、用户文本，返回本次回复 ID；文本增量通过受控事件发送。
- `sanmao:cancel`：取消指定回复。
- 所有请求对象使用 Zod strict schema，限制文本长度、ID 格式、URL 和模型字段；未知字段一律拒绝。

## 页面与交互

- 侧边栏在“制作台”之后增加“三脚猫”，使用 Lucide 对话图标，样式和键盘导航与其他顶级导航一致。
- 页面采用安静的工作台布局：顶部为助手名称、连接状态和新建会话按钮，中间为消息列表，底部为自动增高的输入框、发送和停止按钮。
- 未配置时显示连接表单；已配置时可折叠修改。保存成功、测试中、连接成功和失败均有明确状态。
- 用户消息与助手消息有清晰的主次层级；空会话只保留简短输入入口，不展示营销说明或功能教程。
- 发送后显示流式文本和等待状态；可以停止；失败保留草稿并允许重试。新建会话需清理当前消息和待处理请求状态。
- 文本长词、代码块、窄窗口和 200% 缩放不得遮挡输入区或导航。

## 测试与验收

- 通过依赖注入模拟 SDK query，不依赖真实 API 做单元测试。
- 覆盖配置加密与密钥不泄露、严格 IPC、流式文本、取消、超时、会话隔离、旧请求落在新会话的防护。
- 覆盖导航层级、未配置表单、发送/停止/新建会话、错误重试和切页保留消息。
- 运行类型检查、完整 Vitest（继续排除用户既有环境向导修改）、Studio E2E 和打包测试。
- 构建 Windows 安装包与便携版，核对 SDK 依赖进入包内且测试密钥不进入包。
- 真实 Claude 验收必须复用用户已有授权或等待用户提供测试配置；没有有效授权时明确报告未做真实连接验收。
