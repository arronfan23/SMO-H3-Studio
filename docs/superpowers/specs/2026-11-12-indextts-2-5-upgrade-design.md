# SMO.H3 Studio IndexTTS-2.5 升级设计

## 目标

将语音组件从 IndexTTS-2 完整升级为官方 IndexTTS-2.5，保留现有作品、数字模特、参考音和旧模型文件，并在两个语音模式中提供原生语速控制。

## 官方版本与模型边界

- 源码固定到官方 `v2.5.0` 提交 `39207d91c30899cad1e7c1b9eb678c241f678e55`。
- 主模型使用 `IndexTeam/IndexTTS-2.5`，固定到提交 `c39ce5ba981572cb187443877ff559dfb246ce63`。
- 推理入口改为 `indextts.infer_v2_5.IndexTTS2`，模型目录为 `IndexTTS-2.5`。
- 主模型清单包含 `codec.pth`、`config.yaml`、`feat1.pt`、`feat2.pt`、`gpt.pth`、`s2mel.pth`、`wav2vec2bert_stats.pt`、多语言 tiktoken 文件、许可证和完整情绪模型目录。
- 2.5 的 `codec.pth` 取代 2.0 使用的独立 MaskGCT 辅助模型。w2v-bert-2.0 需要完整模型权重，不能只保留特征提取器配置。
- 辅助模型安装到官方 2.5 读取的 `IndexTTS-2.5/hf_cache` 平铺目录：完整 `w2v-bert-2.0/`、`bigvgan/` 和 `campplus_cn_common.bin`。
- 所有下载继续使用固定 revision、文件大小和 SHA256 校验。旧 Qwen 与 IndexTTS-2 文件不自动删除，用户仍可保留作回退或手动清理。

## 语音服务

- 构造模型时使用 `use_bf16=torch.cuda.is_available() and torch.cuda.is_bf16_supported()`；不支持 BF16 的设备使用官方全精度回退。保持 `use_cuda_kernel=False`、`use_deepspeed=False`，避免引入额外 Windows 原生编译依赖。
- 加载情绪模型以保留“参考音合成”的 `use_emo_text` / `emo_text` 能力；“声音克隆”继续只使用文字和参考音。
- 语言选项更新为中文、英语、日语、西班牙语和阿拉伯语，分别映射到官方 `ZH`、`EN`、`JA`、`ES`、`AR`。默认中文，不再提供 2.5 推理接口不支持的 `Auto`。
- 两种模式都传递 `lang`。语言是生成参数，同时保留在作品元数据中。
- 服务继续只监听 loopback，参考音仍需经过主进程授权；输出 WAV 后再沿用现有转换流程输出 WAV/MP3/FLAC/M4A。

## 语速控制

- 两个语音模式都增加“语速”滑块，显示 `0.50x` 到 `2.00x`，步进 `0.05x`，默认 `1.00x`。
- UI 数值表示直观的播放速度：数值越大，说话越快。
- 主进程和 Python 服务都校验该范围为有限数值。服务将语速转换为官方参数 `duration_factor = 1 / speech_rate`，并传给 `infer()`。
- 不使用 FFmpeg 后处理，不改变音调，也不把语速文字混入情绪提示。
- `speechRate` 是可选请求字段，缺省为 `1.0`，因此旧作品和重试请求保持兼容；新作品元数据记录实际语速。

## 界面与状态

- 保留现有“参考音合成 / 声音克隆”模式、录音、拖入参考音、预览和输出格式。
- 语速滑块与语言、输出格式放在同一设置区域，切换语音模式或应用页面后保留草稿。
- 语音组件状态以新清单为准。已有 2.0 文件不会被视为 2.5 已安装；用户安装语音组件时下载新增文件并显示真实进度。
- 安装或加载失败时显示可重试错误，不自动删除旧模型，不并行启动多个语音服务实例。

## 运行时与打包

- 保持独立 Python 3.11 环境和 Windows x64 CUDA PyTorch 2.8 系列。
- 更新 `pyproject.toml` 与 `uv.lock`，使用官方固定源码提交；启动时执行现有 `uv sync --locked` 完成环境升级。
- 安装包只携带服务源码、锁文件和清单，不内置大模型。
- 更新便携版、安装包和打包测试，确保旧 `infer_v2` 调用及 2.0 模型路径不再进入运行时。

## 测试与验收

- 先添加失败测试，再实现：2.5 模型路径、BF16 构造参数、语言映射、语速边界与倒数映射、两种模式请求、草稿保留和清单布局。
- 重新生成并解析媒体清单，验证所有 revision、SHA256、文件大小、总字节数和路径冲突检查。
- 运行 Python 服务测试、语音与跨页面单元测试、类型检查和完整回归；环境向导的既有未提交修改不纳入本次工作。
- 构建 Windows 安装包和便携版，核对包内服务及锁文件哈希。
- 在本机安装 2.5 组件后执行真实模型验收：中文参考音生成、`1.00x` 与明显不同的语速样例、情绪文本样例和一种非中文样例。真实模型未验收前不宣称生成质量或性能通过。
