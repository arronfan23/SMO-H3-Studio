## 已确认的下载与安装方向

- 采用小型安装器，按需下载和校验，不制作近 200 GiB 的单文件安装包。
- 当前 ComfyUI 运行环境约 24.23 GiB，模型目录约 175.04 GiB，合计约 199.27 GiB。
- 安装器负责硬件检测、清单选择、断点续传、SHA256 校验、剩余空间检查、原子安装和失败回滚。
- 运行环境与模型分开打包和版本化，下载源与登录服务分离，可接 GitHub、对象存储或现有域名。
- 只为已实测的硬件配置提供安装包。当前已验证的是 RTX 5080、INT8、16GB；BF16 和其他硬件没有实测时不得宣称兼容。
- 公开分发模型和第三方节点前，必须核对许可证与再分发权限。

## 已确认的登录方向

- 软件源码和版本发布放 GitHub，账号与令牌数据放用户自己的 Linux 服务器，不把密码或数据库放进 GitHub。
- 用户希望任何人都能注册使用，后续通过会员区分功能；本期先不实现登录与会员。
- 域名：`www.sanmaocloud.com`，已有 HTTPS 和 Next.js 网站。新 API 必须使用独立路径或独立子域名，不覆盖现有站点。
- 桌面端凭据继续使用 Electron `safeStorage`，服务器不存明文密码，令牌需要过期与轮换机制。
